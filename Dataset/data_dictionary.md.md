\# Data Dictionary



\## Raw Tables



\### fact\_sales



| Column Name | Description |

|---|---|

| order\_number | Unique identifier for each order |

| order\_date | Date when the order was placed |

| customer\_key | Unique customer identifier |

| product\_key | Unique product identifier |

| sales\_amount | Revenue generated from the order |

| quantity | Number of units sold |



\### customers



| Column Name | Description |

|---|---|

| customer\_key | Unique customer identifier |

| customer\_id | Unique customer identifier |

| customer\_number | Unique customer identifier |

| first\_name | Name of the customer |

| last\_name | Name of the customer |

| country | Country of the customer |

| birthdate| Customer Birthdate|

| gender | Customer gender, if available |



\### products



| Column Name | Description |

|---|---|

| product\_key | Unique product identifier |

| product\_id | Unique product identifier |

| product\_number | Unique product identifier |

| product\_name | Name of the product |

| category | Product category |

| subcategory | Product subcategory |

| cost | Product cost |



\## Processed Tables



\### customer\_report



| Column Name | Description |

|---|---|

| customer\_key | Unique customer identifier |

| customer\_segment | Customer segment such as VIP, Regular, or New |

| total\_orders | Total orders placed by the customer |

| total\_sales | Total revenue generated by the customer |

| total\_quantity | Total quantity purchased by the customer |

| lifespan | Customer active period |

| recency | Time since the customer's last purchase |

| avg\_order\_value | Average revenue per order |

| avg\_monthly\_spend | Average monthly spend by the customer |



\### product\_report



| Column Name | Description |

|---|---|

| product\_key | Unique product identifier |

| product\_name | Name of the product |

| category | Product category |

| subcategory | Product subcategory |

| product\_segment | Product performance segment |

| total\_orders | Total orders for the product |

| total\_sales | Total revenue generated by the product |

| total\_quantity | Total quantity sold |

| total\_customers | Unique customers who purchased the product |

| recency | Time since the product was last sold |

| avg\_order\_revenue | Average revenue per order for the product |

| avg\_monthly\_revenue | Average monthly revenue for the product |
